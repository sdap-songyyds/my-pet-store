# MyCourseStore 需求

这是一个软件开发架构平台实验作业。我们要完成一个前后端不分离的商店项目，具备基本演示功能。

## 开发工具

- 语言：Java
- Java版本：Java 27
- 框架：Spring（Spring Boot 启动项目，基于Spring IoC和Spring AOP原理，使用Spring MVC框架和MyBatis Plus框架）
- 前端模板引擎：Thymeleaf
- 数据库：PostgreSQL（原始要求 MySQL，此处根据实际情况换用）

## 功能

商品展示。具有主页推荐、商品分类、商品搜索、商品详情页。

用户账户。用户可以注册、登录、退出，基于用户进行身份校验，管理其购物车和订单等。（为了简单，我们使用 JWT 无状态认证。）

购物车。用户可以将想要的商品及其信息加入购物车，便于收纳购买。

订单。记录用户的下单、支付（模拟）与交付状态。

后台管理。商户可以使用管理员账户登录。管理商品信息、分类、库存，管理用户列表（查询、删除、重置密码）、管理订单（查询、删除、更改状态、发货）。
